# Contributing

External contributions are not accepted until assessment is complete.

## Commits

Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/): `type(scope): summary`, for example `feat(app): add tool argument models`. Common types: `feat`, `fix`, `docs`, `test`, `refactor`, `build`, `ci`, `chore`.

New Python files start with the two-line SPDX header (`SPDX-FileCopyrightText` and `SPDX-License-Identifier: MIT`) above the module docstring.
